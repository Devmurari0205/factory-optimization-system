# 🏭 Factory Reallocation & Shipping Optimization System

## 📌 Project Overview

This project is an **end-to-end Data Analytics + Machine Learning + Streamlit Dashboard solution** designed for **Nassau Candy Distributor**.

It transforms traditional logistics operations into a **data-driven decision intelligence system**.

---

## 🎯 Problem Statement

Nassau Candy Distributor currently uses **static rules** to assign products to factories, leading to:

* ❌ High shipping lead times
* ❌ Inefficient logistics routes
* ❌ Reduced profit margins

👉 This project solves these issues using:

* Predictive analytics
* Scenario simulation
* Optimization recommendations

---

## 🚀 Solution Approach

### 1. Data Processing

* Cleaned dataset
* Handled missing values
* Converted date columns
* Feature engineering (Lead Time)

### 2. Machine Learning Model

* Random Forest Regressor
* Predicts **shipping lead time**

### 3. Simulation Engine

* Simulates assigning a product to different factories
* Predicts performance for each scenario

### 4. Recommendation System

* Ranks factories based on:

  * Lead time reduction
  * Efficiency improvement

### 5. Streamlit Dashboard

Interactive web app for real-time decision-making

---

## 📊 Dashboard Features

### 🏭 Factory Optimization Simulator
